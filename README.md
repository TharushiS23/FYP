Explainable Brain Tumour Classification from MRI Scans
This repository contains my final year university project on brain tumour classification using deep learning and explainable AI techniques. The focus of the project is not only on prediction accuracy, but also on understanding why the model makes a decision. The work is implemented using PyTorch and tested using MRI brain scan images.

Project Overview
The goal of this project is to classify brain MRI images into four categories:

Glioma
Meningioma
Pituitary tumour
Normal (healthy brain)

Pretrained CNN models are used for classification, and Grad-CAM / Grad-CAM++ is applied to visually explain model predictions. This helps highlight the regions of the MRI that influenced the model's decision, which is crucial for medical use cases.

Dataset
The dataset used is the Brain Tumor MRI Dataset from Mendeley Data, a publicly available and widely used dataset.

Source: https://data.mendeley.com/datasets/m7w55sw88b/1
Image Type: T1-weighted contrast-enhanced MRI scans
Classes: Glioma, Meningioma, Pituitary tumour, Normal
Note: The dataset is not collected by me. It was downloaded from the above source and used for academic purposes.

Notebooks

This notebook contains:

Preprocessing Steps
The preprocessing pipeline includes:

Reading MRI images and converting formats
Resizing all images to 224 × 224
Data augmentation (rotation, flipping, brightness/contrast)
Conversion to PyTorch tensors
Normalization using standard mean and standard deviation values

Dataset Split

70% Training
10% Validation
20% Test

Explainable AI
Explainability is handled using:

Grad-CAM (manual and library-based)
Grad-CAM++

These methods are applied to ResNet50 to visualize important regions in MRI images that influence predictions. The explanations are checked visually to ensure they align with tumour regions.
